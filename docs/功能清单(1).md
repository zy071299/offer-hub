# 功能清单

本文档列出刷题猫平台的完整功能点，按模块分组，标注优先级和权限要求。

优先级说明：P0 是核心功能，没有它产品跑不起来；P1 是重要功能，影响核心体验；P2 是锦上添花，可以后做。

## 用户权限矩阵

|功能|游客|注册用户|
|---|---|---|
|浏览题库分类|✅|✅|
|浏览题目列表|✅|✅|
|查看题目部分内容（前150字，无解析）|✅|✅|
|查看题目完整内容与解析|❌|✅|
|按难度、标签、关键词筛选题目|✅|✅|
|按掌握状态筛选题目|❌|✅|
|查看热门题目|✅|✅|
|查看评论列表|✅|✅|
|发表评论|❌|✅|
|回复评论|❌|✅|
|修改自己的评论|❌|✅|
|删除自己的评论|❌|✅|
|点赞题目|❌|✅|
|取消点赞|❌|✅|
|标记题目掌握状态|❌|✅|

## 认证模块

|功能|优先级|说明|
|---|---|---|
|用户注册（账号密码）|P0|用户名唯一，密码最少6位|
|用户登录|P0|登录成功返回 JWT token 和用户信息|
|用户登出|P1|token 写入 Redis 黑名单，TTL 等于剩余有效期|
|获取当前用户信息|P0|需要登录，返回用户基本资料|

## 题库模块

|功能|优先级|说明|
|---|---|---|
|题库全量列表（按职位方向分组）|P0|返回所有系列及其下属题库，用于题库分类页|
|题目列表（含分页）|P0|支持按 `bank_id` 过滤，默认按 `order` 排序|
|题目列表过滤（难度、关键词）|P1|多条件组合过滤|
|题目列表过滤（掌握状态）|P1|需要登录，按 `user_tag` 过滤|
|题目列表排序（浏览数、点赞数等）|P2|`sort_by` \+ `sort_order` 参数|
|题目元数据列表（仅 ID \+ 标题）|P1|用于题目导航侧边栏|
|题目详情（游客截断内容）|P0|正文截断至150字|
|题目详情（登录用户完整内容）|P0|附加 `user_liked`、`user_tag` 字段|
|热门题目列表|P1|按 `hot_degree` 降序，支持按职位方向过滤|
|标记题目掌握状态|P1|需要登录，upsert `user_question_tag`|

## 互动模块

|功能|优先级|说明|
|---|---|---|
|点赞题目/评论|P1|需要登录，写入 `user_interactions`，同步更新`question`或`comments`的 `thumbs_up_count`|
|取消点赞题目/评论|P1|需要登录，更新`user_interactions`的 `status=0`，同步更新计数|

## 评论模块

|功能|优先级|说明|
|---|---|---|
|评论列表（顶层评论 \+ 子评论）|P1|软鉴权，顶层评论分页，每条附带前5条子评论|
|发表评论|P1|需要登录，内容经过敏感词过滤|
|回复评论|P1|需要登录，`parent_id` 不为空，`reply_to` 指向被回复用户|
|修改评论|P2|需要登录，只能修改自己的评论|
|删除评论|P1|需要登录，只能删除自己的评论，软删除（`status=5`）|
|获取用户被点赞数|P2|需要登录，统计当前用户所有评论被点赞的总数|

## 首页模块

|功能|优先级|说明|
|---|---|---|
|首页聚合数据|P1|返回热门题目列表，用于首页展示|
|热门题目页|P1|独立页面，展示热门题目列表|
