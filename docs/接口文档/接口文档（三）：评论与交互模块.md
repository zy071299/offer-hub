# 接口文档（三）：评论与交互模块

本文档列出评论模块和用户交互模块的完整接口。通用规范见接口文档（一）。

评论列表使用软鉴权，游客和登录用户都能访问。发表、删除、修改评论需要强制登录。点赞和取消点赞也需要强制登录。

## GET /api/v1/open/list\_comments 评论列表

**鉴权**：软鉴权

**请求参数**：

|参数|类型|必填|说明|
|---|---|---|---|
|`target_type`|int|是|评论对象类型：1题目 / 2面经|
|`target_id`|string|是|评论对象 ID|
|`parent_id`|string|否|父评论 ID，为空时返回顶层评论列表，不为空时返回该评论的子评论列表|
|`sort_by`|string|否|排序字段：create\_time / view\_count / thumbs\_up|
|`sort_order`|string|否|排序方向：asc / desc|
|`page`|int|否|页码，默认 1|
|`page_size`|int|否|每页数量，默认 20|
|`sub_comment_page`|int|否|子评论页码，默认 1|
|`sub_comment_size`|int|否|子评论每页数量，默认 5|

**响应**：

```JSON
{
  "code": 0,
  "msg": "success",
  "data": {
    "total": 50,
    "list": [
      {
        "comment_id": "c001",
        "user_id": "u001",
        "user_name": "testuser",
        "user_avatar": "https://example.com/avatar.jpg",
        "content": "这道题解析写得很清楚",
        "parent_id": "",
        "reply_to": "",
        "reply_to_name": "",
        "status": 2,
        "thumbs_up": 10,
        "sub_comment_total": 3,
        "user_liked": false,
        "sub_comments": [
          {
            "comment_id": "c002",
            "user_id": "u002",
            "user_name": "user2",
            "user_avatar": "https://example.com/avatar2.jpg",
            "content": "同意，讲得很好",
            "parent_id": "c001",
            "reply_to": "u001",
            "reply_to_name": "testuser",
            "status": 2,
            "thumbs_up": 2,
            "sub_comment_total": 0,
            "user_liked": false,
            "sub_comments": [],
            "create_time": "2024-01-02 10:00:00",
            "update_time": "2024-01-02 10:00:00"
          }
        ],
        "create_time": "2024-01-01 12:00:00",
        "update_time": "2024-01-01 12:00:00"
      }
    ]
  }
}
```

顶层评论每条默认附带前5条子评论，存放在 `sub_comments` 数组中。`sub_comment_total` 是该顶层评论下的子评论总数，前端据此判断是否显示"查看更多回复"。

`parent_id` 不为空时，接口只返回该父评论下的子评论列表，不再嵌套 `sub_comments`。

## POST /api/v1/comment/add 发表评论

**鉴权**：强制登录

**请求体**：

```JSON
{
  "target_type": 1,
  "target_id": "q001",
  "parent_id": "",
  "reply_to": "",
  "content": "这道题解析写得很清楚"
}
```

|参数|类型|必填|说明|
|---|---|---|---|
|`target_type`|int|是|评论对象类型：1题目 / 2面经|
|`target_id`|string|是|评论对象 ID|
|`parent_id`|string|否|父评论 ID，顶层评论时为空|
|`reply_to`|string|否|被回复的用户 ID，顶层评论时为空|
|`content`|string|是|评论内容，经过敏感词过滤|

**响应**：

```JSON
{
  "code": 0,
  "msg": "success",
  "data": {
    "comment_id": "c001",
    "comment": {
      "comment_id": "c001",
      "user_id": "u001",
      "user_name": "testuser",
      "user_avatar": "https://example.com/avatar.jpg",
      "content": "这道题解析写得很清楚",
      "parent_id": "",
      "reply_to": "",
      "reply_to_name": "",
      "status": 2,
      "thumbs_up": 0,
      "sub_comment_total": 0,
      "user_liked": false,
      "sub_comments": [],
      "create_time": "2024-01-01 12:00:00",
      "update_time": "2024-01-01 12:00:00"
    }
  }
}
```

## POST /api/v1/comment/delete 删除评论

**鉴权**：强制登录

**请求体**：

```JSON
{
  "comment_id": "c001"
}
```

**响应**：

```JSON
{
  "code": 0,
  "msg": "success"
}
```

软删除，将评论 `status` 更新为 5。只能删除自己的评论，删除他人评论返回 `code: 403`。

## POST /api/v1/comment/update 修改评论

**鉴权**：强制登录

**请求体**：

```JSON
{
  "comment_id": "c001",
  "content": "修改后的评论内容"
}
```

|参数|类型|必填|说明|
|---|---|---|---|
|`comment_id`|string|是|评论 ID|
|`content`|string|是|修改后的内容，经过敏感词过滤|

**响应**：

```JSON
{
  "code": 0,
  "msg": "success",
  "data": {
    "comment_id": "c001"
  }
}
```

只能修改自己的评论，修改他人评论返回 `code: 403`。

## GET /api/v1/comment/user/liked\_collected\_count 获取被点赞数

**鉴权**：强制登录

**请求参数**：无

**响应**：

```JSON
{
  "code": 0,
  "msg": "success",
  "data": {
    "liked_count": 42,
    "collected_count": 0
  }
}
```

统计当前登录用户所有评论被点赞的总数。`collected_count` 当前始终为 0，项目不支持收藏功能。

## POST /api/v1/interaction/like 点赞

**鉴权**：强制登录

**请求体**：

```JSON
{
  "target_type": 1,
  "target_id": "q001"
}
```

|参数|类型|必填|说明|
|---|---|---|---|
|`target_type`|int|是|目标类型：1题目 / 2面经 / 3评论|
|`target_id`|string|是|目标 ID|

**响应**：

```JSON
{
  "code": 0,
  "msg": "success",
  "data": {
    "liked": true,
    "count": 257
  }
}
```

`liked` 表示操作后的点赞状态，`count` 是目标当前的总点赞数。

## POST /api/v1/interaction/unlike 取消点赞

**鉴权**：强制登录

**请求体**：

```JSON
{
  "target_type": 1,
  "target_id": "q001"
}
```

**响应**：

```JSON
{
  "code": 0,
  "msg": "success",
  "data": {
    "count": 256
  }
}
```

`count` 是取消点赞后目标的总点赞数。
