# 数据字典

本文档列出刷题猫平台所有数据模型的完整字段定义。数据库分工：MySQL 只存用户信息，其余全部存 MongoDB。

## MySQL

### `t_user_info` 用户表

|字段|类型|必填|默认值|说明|
|---|---|---|---|---|
|`id`|int|是|自增|主键|
|`user_id`|varchar\(256\)|是|\-|用户唯一标识，UUID，全局唯一|
|`username`|varchar\(50\)|是|\-|登录用户名，全局唯一|
|`password`|varchar\(100\)|是|\-|bcrypt 加密后的密码，不存明文|
|`nick_name`|varchar\(256\)|是|`''`|昵称，展示用，默认与 username 相同|
|`avatar`|varchar\(256\)|是|`''`|头像图片 URL|
|`introduction`|varchar\(1024\)|是|`''`|个人简介|
|`phone`|varchar\(256\)|是|`''`|手机号|
|`email`|varchar\(256\)|是|`''`|邮箱|
|`sex`|tinyint|否|`1`|性别：1未知 / 2男 / 3女|
|`vip`|tinyint|否|`0`|是否 VIP：0否 / 1是|
|`user_status`|tinyint|否|`1`|账号状态：1正常 / \-1禁用|
|`user_type`|tinyint|否|`1`|用户类型：1普通用户 / 2内测用户|
|`create_time`|datetime|否|`CURRENT_TIMESTAMP`|注册时间|
|`update_time`|datetime|否|`CURRENT_TIMESTAMP ON UPDATE`|最后更新时间|

索引：`uk_user_id`（唯一）、`uk_username`（唯一）、`idx_phone`、`idx_email`

## MongoDB

### `question_bank_series` 题库系列集合

题库的顶层分类，比如后端开发、前端开发、AI开发。

|字段|类型|说明|
|---|---|---|
|`_id`|ObjectID|MongoDB 主键|
|`series_id`|string|系列唯一标识|
|`series_name`|string|系列名称，如后端开发|
|`job_name`|string|对应职位方向|
|`order`|int64|排序权重，值越小越靠前|
|`create_time`|datetime|创建时间|
|`update_time`|datetime|更新时间|

### `question_bank` 题库集合

系列下的具体题库，比如 MySQL题库、Redis题库。

|字段|类型|说明|
|---|---|---|
|`_id`|ObjectID|MongoDB 主键|
|`bank_id`|string|题库唯一标识|
|`series_id`|string|所属系列 ID|
|`bank_name`|string|题库名称，如 MySQL题库|
|`bank_logo`|string|题库图标 URL|
|`desc`|string|题库描述|
|`job_name`|string|所属职位方向|
|`order`|int64|排序权重|
|`create_time`|datetime|创建时间|
|`update_time`|datetime|更新时间|

### `question` 题目集合

|字段|类型|说明|
|---|---|---|
|`_id`|ObjectID|MongoDB 主键|
|`question_id`|string|题目唯一标识|
|`title`|string|题目标题|
|`content`|string|题目正文，Markdown 格式|
|`analysis_content`|string|题目解析，Markdown 格式；游客详情响应为空字符串|
|`bank_list`|\[\]string|所属题库 ID 列表，一道题可属于多个题库|
|`job_name`|string|所属职位方向|
|`difficulty`|int|难度：1简单 / 2中等 / 3困难|
|`tags`|\[\]string|技术标签列表，如 `["Redis", "数据库"]`|
|`status`|int|状态：1正常 / 2隐藏 / 3删除|
|`vip`|bool|是否 VIP 专属题目|
|`hot_degree`|int|热度值，用于热门题目排序|
|`view_count`|int|浏览次数|
|`thumbs_up_count`|int|点赞数|
|`dislike_count`|int|点踩数|
|`order`|int64|排序权重|
|`create_time`|datetime|创建时间|
|`update_time`|datetime|更新时间|

接口返回题目时，还会动态附加以下字段（需要登录才有值）：

|字段|类型|说明|
|---|---|---|
|`user_liked`|bool|当前用户是否已点赞|
|`user_tag`|int|当前用户的掌握状态，0表示未标记|

### `comments` 评论集合

|字段|类型|说明|
|---|---|---|
|`_id`|string|MongoDB 主键|
|`comment_id`|string|评论唯一标识|
|`target_type`|int|评论对象类型：1题目 / 2面经|
|`target_id`|string|评论对象 ID|
|`question_id`|string|所属题目 ID|
|`user_id`|string|评论者用户 ID|
|`content`|string|评论内容|
|`parent_id`|string|父评论 ID，为空表示顶层评论|
|`reply_to`|string|被回复的用户 ID，顶层评论为空|
|`child_count`|int|子评论数量，二级评论该字段为 0|
|`thumbs_up`|int|点赞数|
|`view_count`|int|浏览量|
|`status`|int|状态：1审核中 / 2正常 / 3拒绝 / 4隐藏 / 5删除|
|`create_time`|datetime|发表时间|
|`update_time`|datetime|更新时间|

### `user_interactions` 用户交互集合

点赞、点踩等交互行为统一存在这张集合，用 `interaction_type` 区分类型。

|字段|类型|说明|
|---|---|---|
|`_id`|ObjectID|MongoDB 主键|
|`user_id`|string|用户 ID|
|`target_type`|int|目标类型：1题目 / 2面经 / 3评论|
|`target_id`|string|目标 ID|
|`interaction_type`|int|交互类型：1点赞 / 2点踩|
|`status`|int|状态：1有效 / 0无效（已取消）|
|`create_time`|datetime|创建时间|
|`update_time`|datetime|更新时间|

### `user_question_tag` 用户题目标记集合

|字段|类型|说明|
|---|---|---|
|`_id`|ObjectID|MongoDB 主键|
|`user_id`|string|用户 ID|
|`question_id`|string|题目 ID|
|`tag`|int|掌握状态：0未标记 / 1已掌握 / 2晚点再刷 / 3未掌握|
|`create_time`|datetime|创建时间|
|`update_time`|datetime|最后更新时间|
