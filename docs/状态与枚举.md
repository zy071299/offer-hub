# 状态与枚举

本文档集中列出项目中所有枚举值和状态码，供开发时快速查阅，避免在各模块代码里反复翻找。

## 用户相关

### user\_status（账号状态）

|值|含义|
|---|---|
|`1`|正常|
|`-1`|禁用|

### user\_type（用户类型）

|值|含义|
|---|---|
|`1`|普通用户|
|`2`|内测用户|

### sex（性别）

|值|含义|
|---|---|
|`1`|未知|
|`2`|男|
|`3`|女|

### vip（是否 VIP）

|值|含义|
|---|---|
|`0`|否|
|`1`|是|

## 题目相关

### difficulty（难度）

|值|含义|
|---|---|

|`3`|困难|

### question\.status（题目状态）

|值|含义|
|---|---|
|`1`|正常|
|`2`|隐藏|
|`3`|删除|

### question\.vip（是否 VIP 专属）

## 用户题目标记

### user\_question\_tag\.tag（掌握状态）

|值|含义|前端 UI 表现|
|---|---|---|
|`0`|未标记|不显示徽章|
|`1`|已掌握|绿色徽章 \+ 对勾图标|
|`2`|晚点再刷|橙色徽章 \+ 时钟图标|
|`3`|未掌握|红色徽章 \+ X 图标|

## 接口响应码

所有接口统一使用以下响应码，HTTP 状态码始终为 200。

|code|含义|
|---|---|
|`200`|成功|
|`400`|参数错误|
|`401`|未认证（token 无效或已过期）|
|`403`|无权限|
|`500`|服务器内部错误|

## 软鉴权说明

题目相关接口使用软鉴权（`SoftJWTAuthMiddleware`）。

|场景|行为|
|---|---|
|请求头无 token|放行，`user_id` 为空，按游客处理|
|请求头有有效 token|解析 `user_id` 存入 context，按登录用户处理|
|请求头有无效 token|放行，`user_id` 为空，按游客处理|

游客访问题目详情时，后端截断 `content` 至前150字，并将 `analysis_content` 置为空字符串。
